# Fire-Ice
# 🔥❄️ Cinematic Hand Power Engine

A real-time cinematic hand-tracking visual effects engine built using HTML5 Canvas and MediaPipe Hands.

Control elemental powers with your hands directly from your webcam:
- 🔥 Fire
- ❄️ Ice

The project uses advanced particle systems, glow rendering, gesture recognition, and dynamic lighting to create movie-like visual effects in the browser.

---

# ✨ Features

- Real-time hand tracking
- Multi-hand support
- Fire particle engine
- Ice particle engine
- Pinch gesture detection
- Open-hand power activation
- Cinematic dark mode rendering
- Fullscreen immersive visuals
- Zero backend required

---

# 🎮 Controls

| Key | Power Mode |
|-----|-------------|
| `1` | Fire & Ice |

---

# 🖐️ Gestures

## Open Hand
Activates energy around the hand.

## Pinch Gesture
Creates concentrated elemental effects.
